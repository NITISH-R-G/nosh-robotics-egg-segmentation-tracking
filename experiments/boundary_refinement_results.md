None of the 34 refined masks is bit-identical to its original (all hashes differ), but they agree closely: re-prompting SAM with the candidate's own bounding box mostly reproduces the same mask, so it cannot repair occlusion-shaped, boxy or partial proposals; it changes the boundary by a few pixels.

Runtime is the per-prompt predict time after the image embedding was computed (the embedding itself, `set_image`, is not included); peak GPU memory is `torch.cuda.max_memory_allocated` after a reset before each prompt (model weights and the image embedding were resident).

## Traceability

Refined masks: `outputs/boundary_refinement/<variant>/masks/`, manifests `outputs/boundary_refinement/<variant>/manifest.jsonl` (source image id, original candidate id and mask hash, refined id `R1:`/`R2:` and hash, prompt box, padding, SAM predicted IoU, runtime, GPU memory, code version, checkpoint hash). The candidate cache and all S1 outputs were not modified.

## Decision and limitations

No variant met the pre-registered criteria, so refinement is **not adopted**, no other prompt, padding or threshold is tried, and the selector stays as it was (not frozen). Limits: 17 cases and 16 judged masks per variant; most masks are visually near-identical so ratings are mostly equal; partial blinding only (same reviewer, recognisable mask styles); the single improvement (D124-c76 under V1) and the single degradation (D112-c1 under V2) each rest on one rating step, and A1 needs six improved targets, so no single rating can change the decision. This negative result applies to box prompts built from the candidate's own bounding box, not to every possible refinement method.
